## 🎮 遊戲核心玩法
這是一場對抗 **「混亂 AI」** 的邏輯作戰！

* **家長設置傳送門**：家長在門口或窗外觀察三個真實地標（例如：**紅色機車、早餐店、變電箱**），輸入系統並選擇冒險模式。
* **AI 扭曲現實**：Gemini AI 會根據地標與模式，即時生成一段邏輯崩壞、甚至帶點危險的 **「故障導航指令」**。
* **修復師即刻救援**：學生扮演 **「導航修復師」**，必須在有限的資訊中找出錯誤，將其重新撰寫為正確、安全且通順的現實導航。
* **指揮部鑑定**：AI 指揮官會針對修復成果進行評鑑，並發放 **「假日獎勵代碼」**。

## 🌌 三大戰場模式

1.  **🛸 外星入侵模式**：日常生活用品變成了外星科技。電線桿是能量塔？貓咪是偵查兵？挑戰學生的 **分類辨識能力**。
2.  **⚔️ 古代穿越模式**：家門口變成了武俠世界。超商是悅來客棧？機車是千里馬？考驗學生的 **時代感與詞彙轉換**。
3.  **🏙️ 現代寫實模式**：最貼近生活的安全測驗。導航叫你闖紅燈？叫你走在馬路中間？這是 **交通安全與常識** 的終極測試。

## 🛠️ 技術架構

* **前端**：HTML5, CSS3 (具備動態漸變介面)。
* **後端**：Google Apps Script (GAS)。
* **核心引擎**：Gemini 1.5 Flash API。
* **安全性**：使用 **Script Properties** 封裝 API Key，確保金鑰不外洩。
