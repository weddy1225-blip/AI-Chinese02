🛡️ 異常觀測修復計畫：AI 規則怪談導航
## 專案簡介
這是一個專為 國小四年級學生 設計的 AI 互動式邏輯閱讀遊戲。玩家將化身為「時空觀測員」，在接收到的 6 組情境指令 中，過濾掉受污染的異常訊息，守護現實世界的邏輯穩定。

## 🎮 遊戲核心特色
### 🧪 情境融合敘事
AI 不再只是機械式地條列地點，而是將玩家輸入的地標自然編織進詭異的情境描述中。例如：從「地標 A，閉眼」進化為「當你路過地標 A 的老舊大門時，請務必閉著眼睛走過」。

### 🔍 深度邏輯辨析
每場遊戲固定生成 6 張觀測卡片，其中的異常數量會在 1-3 張 之間隨機波動，打破「只有一個錯誤」的固定思維，考驗學生的細節觀察力。

### ⚖️ 數位精準判答
系統後端採用 硬性比對邏輯，確保判決結果與當次生成的卡片狀態 100% 同步，避免 AI 模糊判斷產生的誤差。

### 🧠 後設認知對照
提供 「查看受感染卡片」 功能，讓學生在任務結束後能立即進行答案校對，思考自己遺漏了哪些關鍵細節。

## 📜 觀測員生存手則 (遊戲規則)
在導航指令中，正常訊號絕對不會出現 以下狀態。若在卡片中看見這些行為，請將其移入 「異常隔離區」：

👁️ 閉眼行為：例如「閉著眼睛走路」、「嘗試在原地閉目養神」。

🔄 回頭動作：例如「忍不住回頭望向後方」、「轉身觀察後方的影子」。

🔴 紅色事物：例如「看見紅色的液體」、「路燈轉為詭異的紅色」。

😊 詭異微笑：例如「老闆對你露出微笑」、「店員臉上掛著止不住的笑容」。

## 👨‍🏫 教學應用建議
閱讀策略訓練：引導學生練習在長句子中快速識別「關鍵動詞」與「環境狀態」。

邏輯矛盾偵測：討論為什麼在「規則怪談」的情境下，原本日常的行為（如老闆微笑）會變成一種威脅。

情境寫作練習：鼓勵學生模仿 AI 的口吻，練習寫出屬於自己的「地標融合式」異常指令。

專案技術支援： Google Apps Script / Gemini 1.5 Flash API / HTML5 Drag & Drop API
